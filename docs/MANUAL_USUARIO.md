# Manual do Usuário — RAE Turbo

Última atualização: 27/04/2026

## Uso básico

1. Abra `RAE_Turbo.exe`.
2. Selecione a pasta de origem dos PDFs.
3. Selecione a pasta de destino.
4. Informe a data inicial no formato `DD/MM/AAAA`.
5. Clique em **Iniciar Automação**.
6. Confira a configuração da unidade.
7. Faça login no RAE quando o navegador abrir.
8. Clique em **Continuar após login** no RAE Turbo.
9. Aguarde o processamento.

## Arquivos de configuração e log

Configuração:

```txt
AppData/Local/RAETurbo/config_unidade.json
```

Log:

```txt
AppData/Local/RAETurbo/rae_turbo_execucao.log
```
